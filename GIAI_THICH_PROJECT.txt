GIAI THICH PROJECT MINESWEEPER
==============================

Tai lieu nay giai thich luong chinh cua project Laravel Minefield:
  - Nguoi dung bam nut nao tren giao dien
  - JavaScript nao bat su kien
  - API nao duoc goi
  - Route Laravel nao tiep nhan
  - Controller xu ly va tra ket qua ra sao

Luu y: Duong dan trong tai lieu duoc viet tu thu muc goc project.


1. TONG QUAN CAC LOP
====================

resources/views/minefield/*.blade.php
  Tao giao dien HTML: form, nut, ban choi, dialog va cac vung hien thi.

public/minefield/js/login.js, modes.js, game.js, shop.js, skins.js
  Bat su kien click/submit tren trang va dieu khien giao dien, cua hang skin.

public/minefield/js/engine.js
  Xu ly luat game: tao min, mo o, dat co, loang o trong, kiem tra thang/thua.
  Engine khong phu thuoc HTML/DOM; tren trinh duyet, danh muc mode/do kho duoc
  nap tu database qua MF_GAME_OPTIONS.

public/minefield/js/api.js
  Gom cac ham gui HTTP request tu trinh duyet den Laravel.

public/minefield/js/ui.js
  Cac thanh phan giao dien dung chung: header, menu tai khoan, dialog,
  leaderboard, toast va dinh dang thoi gian.

routes/web.php
  Noi URL voi view hoac controller method.

app/Http/Controllers/
  Xu ly nghiep vu, validation, session va database.

app/Models/
  Model Laravel dai dien cho cac bang du lieu.

database/migrations/
  Dinh nghia cau truc bang database.

Luong web tong quat:

  Blade view
    -> JavaScript cua trang
    -> api.js (neu can goi API)
    -> routes/web.php
    -> Controller
    -> Model / database / session
    -> JSON response
    -> JavaScript cap nhat giao dien hoac chuyen trang


2. CAC FILE NEN TANG NAP TREN MOI TRANG
========================================

2.1 resources/views/minefield/partials/scripts.blade.php

Partial nay duoc cac trang Minefield include o cuoi body. No:

1. Doc user da dang nhap hoac trang thai guest tu Laravel.
2. Dua thong tin do vao window.MF_INITIAL_SESSION de JavaScript dung.
3. Lay mode va difficulty tu AppServiceProvider, dua vao MF_GAME_OPTIONS.
4. Nap public/minefield/js/config.js.
5. Ghi API_BASE va URL cac trang vao window.MF_CONFIG.
6. Nap cac script theo thu tu:
     engine.js -> api.js -> ui.js -> script rieng cua trang.

Thu tu nay co y nghia: game.js va modes.js can engine/API/UI da duoc nap truoc.

2.2 public/minefield/js/config.js

Chua cau hinh mac dinh, vi du API_BASE. Partial scripts co the ghi de cau hinh
API_BASE va URL dung voi base path hien tai cua Laravel.

2.3 public/minefield/js/api.js

Bien BASE la prefix API, thuong la /api.
Bien session giu thong tin user ban dau trong MF_INITIAL_SESSION.

request(path, options):
  - Dung fetch(BASE + path) de gui request.
  - credentials: same-origin de trinh duyet gui cookie session Laravel.
  - Accept: application/json yeu cau response JSON.
  - Content-Type: application/json cho biet request body la JSON.
  - X-CSRF-TOKEN lay tu meta csrf-token trong trang.
  - Neu response loi, doc errors/message va nem Error de code goi ham co the
    bat bang try/catch.

post(path, data):
  Tao request POST va JSON.stringify(data).

Nhung ham API duoc phoi ra window.MF_API:
  signup(data)           -> POST /api/signup
  login(data)            -> POST /api/login
  adminLogin(data)        -> POST /api/admin/login
  playAsGuest()           -> POST /api/guest
  logout()                -> POST /api/logout
  startGame(data)         -> POST /api/games
  submitResult(data)      -> POST /api/games/{token}/win
  submitLoss(token)       -> POST /api/games/{token}/loss
  getLeaderboard(data)    -> GET /api/leaderboard?...
  getBestTime(data)       -> GET /api/best-time?...
  useHint(token)          -> POST /api/games/{token}/hint
  getShop()               -> GET /api/shop
  buySkin(skinId, type)   -> POST /api/shop/buy
  equipSkin(skinId, type) -> POST /api/shop/equip

getPrefs()/setPrefs():
  Doc va ghi mode/do kho da chon vao localStorage voi key mf_prefs.
  Day la tuy chon tren trinh duyet, khong phai ban ghi database.

2.4 routes/web.php

Route::view('/', 'minefield.login')
  Khi mo /, Laravel render trang login.

Route::view('/modes', 'minefield.modes')
  -> trang chon che do va do kho.
Route::view('/game', 'minefield.game')
  -> trang ban choi.
Route::view('/shop', 'minefield.shop')
  -> trang cua hang trang phuc (Phong Thu Chien Thuat).
Route::view('/admin/login', 'minefield.admin-login')
  Cac route tren tra ve Blade view.

Route::middleware('auth')->group(...)
  Cac route admin trong nhom yeu cau user da dang nhap.
  Controller van kiem tra role admin rieng; middleware auth chi xac nhan dang nhap,
  khong tu dong dam bao user la admin.

Route::prefix('api')->group(...)
  Cac route ben trong co prefix /api.
  Vi du Route::post('/login', ...) tro thanh POST /api/login.

3.3 Gui form dang nhap/dang ky

  Chan trinh duyet tu submit form theo cach mac dinh va tai lai trang.

username.value.trim():
  Lay username va bo khoang trang o dau/cuoi.

password.value:
  Lay mat khau; khong trim vi khoang trang co the la mot phan mat khau.

  Hien loi tren form va return, khong gui API.

await doi server tra ket qua.
Neu thanh cong:

  - role khac -> chuyen /modes
Neu that bai:
  - catch nhan Error tu api.js
  - showError(err.message)

3.5 current(Request $request): JsonResponse

Route: GET /api/session

if ($user = $request->user()) {
    return response()->json($this->userPayload($user));
}

$request->user():
  Lay user dang duoc Laravel xac thuc tu session cookie.

Neu co user:
  Tra ve JSON thong qua userPayload().

Neu khong co user:
  Doc session key minefield.guest.
  - Neu key guest ton tai/truthy: tra object guest.
  - Neu khong: tra JSON null.

Ham nay cung cap thong tin phien hien tai. Trong project, partial scripts
thuong nhung MF_INITIAL_SESSION truc tiep vao HTML; api.js khong goi current()
trong luong dang nhap hien tai.

3.6 signup(Request $request): JsonResponse

Route: POST /api/signup

Khoi validation:

  $data = $request->validate([...]);

Laravel kiem tra du lieu truoc khi tao user:

username:
  required                       bat buoc
  regex:/^[A-Za-z0-9_]{3,20}$/  chi chu, so, dau gach duoi; dai 3-20
  unique:users,username          khong trung username trong bang users

displayName:
  nullable                       co the khong gui
  string                         neu co phai la chuoi
  max:24                         toi da 24 ky tu

password:
  required                       bat buoc
  string                         phai la chuoi
  min:6                          toi thieu 6 ky tu

Neu validation that bai, Laravel tu tra response loi; cac dong sau khong chay.

Khoi tao user:

  $user = User::create([...]);

username:
  Lay tu du lieu da validation.

display_name:
  trim($data['displayName'] ?? '') bo khoang trang.
  Toan tu ?: dung username neu display name bi thieu hoac rong sau khi trim.

password:
  Hash::make(...) bam mat khau truoc khi luu.
  Password goc khong duoc luu thanh van ban trong database.

User::create() tao ban ghi users. Cac truong duoc phep mass-assign nam trong
app/Models/User.php, trong mang $fillable.

Khoi session/dang nhap:

  $request->session()->forget('minefield.guest');
    Xoa trang thai guest cu neu co.

  Auth::login($user);
    Dang nhap ngay user vua tao.

  $request->session()->regenerate();
    Tao session ID moi sau khi thay doi trang thai xac thuc.

Tra ket qua:

  return response()->json($this->userPayload($user), 201);

Tra JSON thong tin user va HTTP status 201 (da tao tai khoan thanh cong).

3.7 login(Request $request): JsonResponse

Route: POST /api/login

Validation:
  username required, string, toi da 20 ky tu.
  password required, string.

Xac thuc:

  Auth::attempt([
      'username' => trim($data['username']),
      'password' => $data['password']
  ])

Laravel tim user theo username va so sanh password gui len voi password bam
trong database. Khong tu so sanh password bang van ban thuong.

Neu Auth::attempt() tra false:
  Nem ValidationException voi thong bao Wrong username or password.
  Request dung tai day va frontend nhan loi.

Neu dung:
  1. Xoa minefield.guest.
  2. Regenerate session.
  3. Lay user vua dang nhap bang $request->user().
  4. Kiem tra user->is_locked.

Neu tai khoan bi khoa:
  Auth::logout() huy dang nhap.
  Nem ValidationException voi thong bao This account is locked.

Neu khong bi khoa:
  Tra userPayload() duoi dang JSON.

3.8 adminLogin(Request $request): JsonResponse

Route: POST /api/admin/login

Validation va Auth::attempt() giong login().

Sau khi username/password dung:

  $user = $request->user();
  if ($user->role !== 'admin' || $user->is_locked) { ... }

Toan tu || la OR. Neu user khong phai admin HOAC dang bi khoa:
  - Auth::logout()
  - Nem loi Admin access is required.

Neu hop le:
  - Xoa trang thai guest.
  - Regenerate session.
  - Tra userPayload().

Frontend admin-login.js sau khi API thanh cong se chuyen /admin.
Backend van kiem tra role khi vao trang admin; khong chi dua vao redirect frontend.

3.9 guest(Request $request): JsonResponse

Route: POST /api/guest

  Auth::logout();
    Neu dang co user login thi dang xuat.

  $request->session()->regenerate();
    Tao session ID moi.

  $request->session()->put('minefield.guest', true);
    Luu trang thai guest trong session.

Sau do tra:
  username null, displayName Guest, role guest, guest true.

login.js xu ly click Play as guest:
  1. preventDefault() chan link chuyen trang ngay.
  2. Goi api.playAsGuest().
  3. Neu thanh cong chuyen den /modes.
  4. Neu loi hien loi tren trang.

3.10 logout(Request $request): JsonResponse

Route: POST /api/logout

  Auth::logout();
    Dang xuat user.

  $request->session()->invalidate();
    Huy session hien tai va xoa du lieu session.

  $request->session()->regenerateToken();
    Tao CSRF token moi.

Tra JSON {loggedOut: true}.

Trong ui.js, nguoi dung bam Log out trong menu avatar:
  ui.js -> api.logout() -> POST /api/logout -> controller logout()
  -> sau khi API xong, api.js dat bien session = null
  -> ui.js chuyen ve trang chu.

3.11 userPayload(User $user): array

Ham private, chi controller nay goi.
Nhan mot User, tra mang gom:
  username
  displayName (lay tu cot display_name)
  role
  guest = false

Khong tra password. Mang nay duoc response()->json() chuyen thanh JSON.

5. LUAT GAME TRONG engine.js
============================

engine.js la logic game doc lap voi giao dien.
No export MinefieldEngine cho browser va co the export module cho Node test.

5.1 MODES

Tren browser, MODES duoc tao tu window.MF_GAME_OPTIONS.modes; AppServiceProvider
doc danh muc nay tu bang game_modes. Khi chay engine test trong Node, engine.js
dung cau hinh mac dinh de cac test logic co the chay doc lap voi Laravel.

Moi mode co:
  id      ma mode
  label   ten hien thi
  hint    mo ta
  offsets danh sach vi tri tuong doi cua cac o neighbor

Vi du Classic co 8 offsets, Plus co 4 offset ngang/doc, Corner co 4 offset cheo.
neighbors(i) dung offsets nay de tinh neighbor cho cac thuat toan.

5.2 DIFFICULTIES

Tren browser, DIFFICULTIES duoc tao tu window.MF_GAME_OPTIONS.difficulties;
AppServiceProvider doc danh muc nay tu bang difficulties.

Moi do kho quy dinh:
  rows   so hang
  cols   so cot
  mines  so min

game.js lay thong so nay de tao Minesweeper.

5.3 Constructor Minesweeper

Nhan rows, cols, mines, mode va tuy chon rng/now.
  - Kiem tra mode co ton tai.
  - Kiem tra so min hop le.
  - Luu kich thuoc, so min va ham random/thoi gian.
  - Tao cache neighbor.
  - Goi reset() de tao trang thai ban moi.

5.4 reset()

Tao mang cells, moi cell co:
  mine, adj, revealed, flagged, exploded.

Dat state = ready, flags/revealedCount = 0, startedAt/endedAt = null.
Goi _emit() de thong bao cho UI neu da gan callback onStateChange.

5.5 neighbors(i)

Chuyen index i thanh row/column.
Cong tung offset cua mode de tao vi tri neighbor.
Bo qua vi tri vuot bien ban co.
Luu ket qua vao _nbCache de khong phai tinh lai.

5.6 reveal(i)

  - Tu choi hanh dong neu game da ket thuc hoac index khong hop le.
  - Khong mo lai cell da mo hoac dang co co.
  - Neu state ready, goi _placeMines(i), bat dau tinh gio va chuyen state playing.
  - Neu cell la min, goi _lose().
  - Neu khong phai min, goi _flood() de mo o.
  - Cuoi cung goi _checkWin().

Mins chi duoc tao khi click dau tien, khong phai luc tai trang.

5.7 _placeMines(safe)

  - Tao tap banned gom o click dau va neighbor cua no.
  - Tao pool cac o duoc phep dat min.
  - Neu pool khong du cho, chi cam dat min vao o click dau.
  - Dung Fisher-Yates de chon vi tri ngau nhien.
  - Tinh adj cho moi o bang cach dem min trong neighbors(i).

5.8 _flood(start, changed)

Dung stack de mo lan:
  - Mo o start.
  - Neu o co adj = 0, dua cac neighbor chua mo/chua co vao stack.
  - Lap cho den khi stack rong.
  - Ghi index cac o vua doi vao changed de UI chi render lai nhung o do.

5.9 toggleFlag(i)

Neu game con dang choi va o chua mo:
  - Dao trang thai flagged.
  - Tang/giam flags.
  - Tra ve danh sach o thay doi.

5.10 chord(i)

Chi ap dung neu o i da mo va co so neighbor min lon hon 0.
Dem so co xung quanh. Neu so co bang adj:
  - Mo cac neighbor chua mo/chua co.
  - Neu mo trung min thi thua.
  - Neu khong thi flood-fill va kiem tra thang.

5.11 _checkWin(changed)

Thang khi so o da mo bang tong so o khong co min.
Khi thang:
  - Dat endedAt.
  - Tu dong danh co cac min chua co.
  - Chuyen state sang won.

5.12 _lose(hit, changed)

  - Dat endedAt.
  - Danh dau o min vua mo la exploded.
  - Danh sach cac o min chua danh co va co sai de UI hien thi.
  - Chuyen state sang lost.

5.13 view(i)

Chuyen trang thai cell thanh loai giao dien:
  number, empty, flag, mine, exploded, wrongflag, hidden.
game.js doc gia tri nay de gan CSS class va SVG.


6. LUONG TRANG GAME TRONG game.js
=================================

Giao dien:
  resources/views/minefield/game.blade.php

JavaScript:
  public/minefield/js/game.js

6.1 Kiem tra session

game.js goi ui.requireSession().
Neu khong co session, ui.requireSession() chuyen ve trang chu va game.js dung.
Neu co session, initHeader() ve header tai khoan.

6.2 Doc mode/do kho

game.js doc query string mode/diff.
Neu URL hop le thi uu tien URL; neu khong thi doc localStorage; neu van sai
thi dung classic/medium.

6.3 configure(mode, difficulty)

Ham nay tao hoac cau hinh lai ban:
  1. Tang runId de danh dau vong choi moi.
  2. Dung timer cu.
  3. Xoa startPromise cu.
  4. Cap nhat mode/difficulty.
  5. Lay rows/cols/mines tu DIFFICULTIES.
  6. Tao Minesweeper moi.
  7. Gan onStateChange.
  8. Cap nhat segmented control, tieu de va document.title.
  9. Luu tuy chon.
  10. Cap nhat query string bang history.replaceState().
  11. buildBoard(), an ket qua cu, cap nhat bo dem.

6.4 buildBoard()

Tao mot button cho moi cell trong game.cells:
  - Gan class cell.
  - Gan data-i la index.
  - Them vao fragment, sau do them fragment vao board.
  - Goi renderCell(i) de ve trang thai ban dau.

6.5 renderCell(i)

Goi game.view(i) lay loai cell.
Dua tren kind:
  - number: hien so va class n1/n2...
  - empty: o trong da mo.
  - flag: hien SVG co.
  - mine/exploded: hien SVG min.
  - wrongflag: hien co sai.
  - hidden: o chua mo.

Gan aria-label de ho tro cong cu doc man hinh.

6.6 apply(changed)

Nhan danh sach index cell vua doi tu engine.
Render lai tung cell trong danh sach va cap nhat bo dem.

6.7 Timer

startTimer() goi setInterval moi 100 ms.
tick() tinh game.elapsedMs() va hien so giay.
stopTimer() clear interval.
Timer lay moc thoi gian tu engine; khong phai moi lan tick cong them mot giay.

6.8 Su kien tren ban

Click trai:
  board click -> tim .cell -> lay data-i -> reveal(i).

reveal(i):
  - Neu cell da mo: thu game.chord(i).
  - Neu chua mo: game.reveal(i).
  - apply() render cac o thay doi.

Chuột phai:
  contextmenu.preventDefault() chan menu trinh duyet.
  Neu khong phai touch thi flag(i).

Cam ung:
  pointerdown touch bat dau timeout 380ms.
  Neu van nhan giu, dat co, ngan click sau do va rung may neu co navigator.vibrate.
  pointerup/cancel/leave huy timeout.

Ban phim:
  F tren cell dang focus -> toggle flag.
  R -> restart, tru truong hop dang focus trong input/textarea/select,
  hoac co dialog dang mo, hoac phim Ctrl/Meta/Alt dang duoc giu.

6.9 Restart

Nut status o giua va phím R goi restart():
  - Tang runId.
  - Dung timer.
  - Xoa startPromise.
  - game.reset().
  - An result.
  - Render lai tat ca o va bo dem.

6.10 State change va goi backend

onStateChange('playing'):
  - Bat timer.
  - Goi api.startGame({mode, difficulty}).
  - Request nay tao token game ben server.

onStateChange('won'):
  - Dung timer.
  - Hien ket qua dang luu.
  - onWin() doi startPromise de lay token.
  - Goi submitResult(token, mode, difficulty, timeMs).
  - Hien record/rank hoac thong bao loi.

onStateChange('lost'):
  - Dung timer.
  - Hien ket qua thua.
  - onLoss() doi token roi goi submitLoss().

runId duoc dung de bo qua ket qua async cua van cu neu nguoi choi restart
hoac doi cau hinh truoc khi response cu tra ve.


7. BACKEND GAME, BEST TIME VA LEADERBOARD
=========================================

Route/controller:
  routes/web.php
  app/Http/Controllers/MinefieldGameController.php

7.1 POST /api/games -> start()

Frontend goi khi state game chuyen sang playing, tuc la sau hanh dong mo o dau.

Controller:
  1. Validate mode va difficulty co trong bang game_modes/difficulties.
  2. Tim model GameMode va Difficulty theo code.
  3. Tao UUID token.
  4. Ghi thoi diem bat dau.
  5. Neu da dang nhap, tao ban ghi games voi user, mode, do kho va status playing.
  6. Neu guest, ghi session game theo token.
  7. Tra JSON gom token, mode, difficulty.

Guest khong tao Game record gan user; thong tin game tam nam trong session.

7.2 POST /api/games/{token}/win -> win()

Controller validate mode, difficulty, timeMs.

Guest:
  - Lay va xoa session game bang session()->pull().
  - Neu khong tim thay token thi 404.
  - Kiem tra mode/do kho gui len khop voi session.
  - Kiem tra time.
  - Tra {saved: false}; guest khong luu leaderboard.

Tai khoan:
  - Chay trong DB::transaction() de cac thay doi lien quan thanh cong/dung bo.
  - Tim game theo token va user hien tai, lockForUpdate() tranh cap nhat dong thoi.
  - Kiem tra game ton tai va dang playing.
  - Kiem tra mode/do kho gui len khop thong tin game.
  - Kiem tra thoi gian bao cao.

13. DE XUAT BOT MINIMAX + ALPHA-BETA DUOI DANG NUT HINT

Trang thai hien tai:

13.1 Vi sao Hint Bot hop voi Minesweeper?

Nguoi choi bam Hint de nhan goi y, nhung van tu quyet dinh mo o hay cam co.
Bot khong tu dong choi thay nguoi dung. Cac goi y co the gom:
  - O an toan chac chan, nen mo.
  - O chac chan co min, nen cam co.
  - Chua du thong tin de ket luan; neu phai doan thi goi y o co rui ro thap hon.

Cach nay phu hop voi Minesweeper hon viec coi game nhu co doi thu co nuoc di.
Minesweeper la bai toan thong tin an: cac con so gioi han nhung vi tri min co
the xay ra, va doi khi nguoi choi bat buoc phai doan.

13.2 Du lieu Bot duoc phep xem

Bot chi nhan thong tin cong khai ma nguoi choi nhin thay:
  - O nao da mo va so min hien tren o do.
  - O nao dang bi danh co.
  - O nao chua mo.
  - Mode hien tai va so min con lai neu game cung cap thong tin nay.

Khong gui danh sach vi tri min that trong cac cell an cho Bot. Engine hien dang
giu thong tin noi bo mine trong game.cells; can tao mot ham snapshot rieng chi
tra ve trang thai cong khai, khong dua truc tiep mang cells noi bo cho Bot.
Neu Bot doc vi tri min an, no khong con la Bot suy luan ma chi doc dap an.

13.3 Vai tro cua suy luan, Minimax va Alpha-Beta

Buoc dau tien la lap rang buoc tu cac o so:
  - Moi o an chua biet la bien co min (1) hoac an toan (0).
  - So tren o da mo bang tong so min trong cac neighbor chua mo, sau khi tru
    cac co da danh dau.
  - Cac rang buoc duoc ket hop de phat hien o chac chan an toan/min.

Neu co nhieu cach sap min cung phu hop voi thong tin, Bot co the tim kiem cac
kha nang do va cham diem cac hanh dong. De giai thich Minimax trong de tai:
  - MAX dai dien Bot chon hanh dong co diem tot nhat.
  - MIN dai dien tinh huong bat loi nhat trong nhom cach sap min van phu hop
    voi cac dau hieu da mo.
  - Ham diem co the uu tien an toan, dong thoi tinh den gia tri thong tin cua
    o mo ra (co the giup suy luan them).
  - Alpha-Beta cat cac nhanh khong the thay doi lua chon tot nhat hien tai.

Day la cach ap dung Minimax theo tinh huong xau nhat cho bai toan co thong tin
an, khong phai Minimax doi khang co dien nhu co vua. Nen ghi ro cach mo hinh hoa
MAX/MIN va ham diem trong bao cao; neu giang vien yeu cau mot mo hinh cu the,
can thong nhat mo ta voi giang vien truoc khi chot bao cao.

13.4 Hai muc do de the hien trong giao dien

  - Dung cac quy tac suy luan don gian tu cac con so.
  - Neu tim thay o chac chan an toan/min thi dua ra goi y do.
  - Neu khong tim thay, thong bao chua du du kien hoac dua ra lua chon co ban.

Kho:
  - Xet nhieu rang buoc va nhieu cach sap min phu hop hon.
  - Dung tim kiem Minimax theo tinh huong xau nhat va Alpha-Beta pruning.
  - Cham diem muc do an toan va gia tri thong tin cua cac nuoc di.
  - Neu khong co nuoc chac chan an toan, noi ro day la goi y co rui ro, khong
    dam bao khong trung min.

Hai muc do phai duoc phan biet bang cach tim kiem/thang diem thuc te, khong chi
doi ten nut hoac chi doi mot chuoi giao dien.

15.4 Kien truc phan tach Engine JS Frontend (0ms Latency) & Backend Database Authority
- Toan bo logic ban co (sinh min an toan sau cu click dau tien, mo o, thuat toan loang Flood-fill, chording, cam co, tim min Hint) chay hoan toan tren trinh duyet trong `public/minefield/js/engine.js` & `game.js`.
- Nho khong phai cho doi HTTP request cho moi cu click/cam co, thao tac choi dat do tre 0ms (zero-latency) cuc ky muot ma khi choi toc do cao.
- Backend Laravel dong vai tro quan ly co so du lieu va chong gian lan:
  + Cap phat Game Token (UUID) va ghi nhan thoi diem `started_at` chinh xac mili-giay khi van dau bat dau (`POST /api/games`).
  + Thuc thi cac giao dich xu an toan (tru 100 xu cho Hint, mua Skin trong `DB::transaction()`).
  + Kiem tra hop le trang thai `playing`, so khop mode/do kho va tham dinh thoi gian chong gian lan (`MIN_PLAUSIBLE_TIME_MS = 200 ms`, `TIME_TOLERANCE_MS = 2.500 ms`) khi luu ket qua thang/thua va cap nhat `records` leaderboard (`POST /api/games/{token}/win`, `/loss`).

17. BO CAU HOI VA DAP AN PHAN BIEN DO AN (Q&A CHO BUOI BAO VE)
==============================================================

Cau 1: Tai sao nhom chon CSDL MySQL ma khong dung MongoDB nhu mot so de tai web khac?
Tra loi:
He thong Minefield co cau truc du lieu quan he chat che (Quan he 1-N giua Users - Games, Users - Records, Users - UserSkins; rang buoc khoa ngoai tham chieu toi game_modes va difficulties). Ngoai ra, MySQL ho tro ACID transaction thong qua DB::transaction() de dam bao an toan so du xu khi mua skin trong Shop va khi luu ket qua tran dau. Chi muc to hop tren MySQL (records_leaderboard_idx) giup toi uu hoa truy van bang xep hang thoi gian thuc.

Cau 2: Tai sao de tai khong tich hop cong thanh toan truc tuyen nhu VNPAY, MoMo hay SePay?
Tra loi:
Theo dung muc "Nhung noi dung khong thuoc pham vi de tai" trong Phieu dang ky de tai chuyen nganh da duoc duyet ("Khong tich hop thanh toan"), nhom tap trung vao co che Play-to-Earn noi bo: nguoi choi dung ky nang vuot qua cac van kho va dat thoi gian nhanh de tich luy Xu ao (Coins), sau do dung xu nay de mua skin hoac goi y mìn. Dieu nay tranh phuc tap ve mat phap ly va chi phi duy tri cong thanh toan thuc te cho mot do an hoc tap.

Cau 3: Tai sao logic ban co Do min van de o Frontend JS (`engine.js`) con Backend Laravel chi xu ly Database, Session va Validate?
Tra loi:
Minesweeper la tro choi phan xa toc do cao voi tan suat nhap chuot va cam co/chord co the len toi 5-10 thao tac moi giay. Neu moi cu click/cam co deu gui HTTP request len backend, do tre mang se gay cam giac giat lag va anh huong trai nghiem nguoi choi. Viec giu Engine thuan o JavaScript frontend (`engine.js`) giup dat do tre 0ms va toi uu render DOM. Trong khi do, Backend Laravel thuc hien dung vai tro quan ly du lieu an toan: luu tru CSDL, cap Game Token, ghi nhan thoi diem `started_at`, tham dinh thoi gian hoan thanh (`TIME_TOLERANCE_MS = 2.500 ms`), tru/cong xu qua `DB::transaction()` va cap nhat Leaderboard.

Cau 4: Co che tinh thuong toc do (Speed Bonus) hoat dong the nao trong ma nguon?
Tra loi:
Trong file app/Services/SkinCatalog.php, ham calculateSpeedBonus(?int $timeMs) kiem tra:
- Neu thoi gian < 30 giay (30,000 ms): thuong them 100 xu.
- Neu thoi gian < 60 giay (60,000 ms): thuong them 50 xu.
- Neu thoi gian < 100 giay (100,000 ms): thuong them 25 xu.
- Tu 100 giay tro len (>= 100,000 ms): +0 xu.
Ham getRewardBreakdown() ket hop muc xu co ban cua do kho (Easy 30, Medium 75, Hard 180), cong them 20% neu la che do bien the (Plus/Corner), va cong them Speed Bonus de ra tong so xu thuong cho van dau.

Cau 5: Thuat toan Goi y min (Hint) hoat dong the nao giua Client va Server?
Tra loi:
Khi nguoi choi nhan nut Hint hoac phim H, he thong gui yeu cau toi `POST /api/games/{token}/hint` de Laravel kiem tra so du xu (>= 100 xu) va tru 100 xu an toan trong `DB::transaction()`. Ngay khi may chu xac nhan thanh cong, ham `applyHint()` trong `public/minefield/js/engine.js` se quet cac o min chua cam co, uu tien chon nhom "frontier" (min tiep giap it nhat 1 o so da mo) de cam co va bat hieu ung radar, giup nguoi choi suy luan cac o xung quanh.

Cau 6: Tai sao tep kiem thu JavaScript lai su dung duoi file .cjs thay vi .js?
Tra loi:
Trong package.json, du an khai bao "type": "module" de ho tro chuan ES Module hien dai. Tep kiem thu tests/js/engine.test.cjs su dung cu phap require() cua CommonJS de doc va kiem thu file engine.js mot cach doc lap. Khi dat duoi .cjs, Node.js se nhan dien chinh xac day la CommonJS script va thuc thi ma khong gay ra xung dot dinh dang module.

Cau 7: He thong bao ve truoc tan cong do quet mat khau (Brute-force) va khoa tai khoan nhu the nao?
Tra loi:
Cac route xac thuc (/api/login, /api/signup, /api/admin/login) deu duoc bao ve boi middleware throttle:10,1 (toi da 10 lan thu trong 1 phut). Neu vuot qua, server tra HTTP 429 Too Many Requests. Ngoai ra, tai khoan nguoi dung co truong is_locked. Khi admin khoa tai khoan, middleware EnsureAccountIsActive se lap tuc huy phien dang nhap va ngan chan moi thao tac gui ket qua len may chu.

Cau 8: Tai sao cot `score` van ton tai trong bang `games` va `records` khi Endless Mode da bo?
Tra loi:
Trong qua trinh phat trien o tuan 11, nhom tung nghien cuu tinh nang Endless Mode tinh bang diem so (migration 2026_11_09_084237). Sau do, de dam bao dung pham vi phieu dang ky la game tinh thoi gian co dien, nhom da go bo mode nay (migration 2026_11_09_091500). CSDL duoc giu nguyen cot score voi gia tri mac dinh 0 de khong lam gian doan cac cau truc migration da chay truoc do, day la quy trinh tieu chuan trong quan ly migration CSDL.

Cau 9: Chuc nang Give Coins trong trang Admin hoat dong nhu the nao?
Tra loi:
Admin co the truy cap modal Dieu chinh so du trong trang quan tri de cong them xu cho bat ky nguoi choi nao qua route POST /admin/users/{user}/give-coins. Admin co the nhap so xu tuy bien (step=1) hoac bam cac muc cong nhanh tu +500 den +999.999 xu. Ham giveCoins() trong MinefieldAdminController kiem tra quyen admin, cong don so du (toi da 2 ty xu) va luu vao CSDL.
